# 3D models

The website uses the saved coordinates in `src/assets/points/`; no GLB is required at runtime.

To re-export, temporarily restore `corona_virus.glb` here from the local `artifacts/source-models/` backup. Start the development server and run `node scripts/export-pathogen.mjs`. Keep the source model out of the published repository after exporting.

Keep the directory name 3D when deploying to Linux.
